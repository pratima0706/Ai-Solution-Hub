AI-Solution Hub - README

1) Overview
- Purpose: Central hub to explore, prototype, and manage AI-powered solutions for coursework and demos.
- Audience: Instructors, reviewers, and contributors who need to understand what the app does and how to run it.
- Scope: Focuses on the admin panel for managing content/configurations; public-facing site is separate and must not be disrupted.

2) Key Features
- Admin panel to curate AI solution entries, descriptions, and resources
- Modular architecture for adding new solution modules or demos
- Environment-based configuration for safe local development
- Consistent scripts for install, run, and build

6) Setup (Windows PowerShell)
- One-time install:
  - npm:  npm install
  - yarn: yarn install

7) Running the App (Local)
- Development mode:
  - npm:  npm run dev
  - yarn: yarn dev
- The dev server usually starts at http://localhost:3000 (confirm if different)

8) Build & Production Preview
- Build:

  - yarn: yarn build
- Preview build locally (if supported):
  - npm:  npm run preview
  - yarn: yarn preview

9) Environment Variables (example)
- Create a .env file in the project root. Do not commit secrets.
- Common variables:
  - NODE_ENV=development
  - API_BASE_URL=http://localhost:3000/api
  - Any provider keys (e.g., OPENAI_API_KEY) as needed

10) Admin Panel Usage
- Goal: Manage AI solution entries without impacting the public site.
- Access: Typically a protected route (e.g., /admin). Confirm the exact path.
- Safeguards:

  - Do not modify the public site while its server is running.
